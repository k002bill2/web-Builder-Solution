## 해야 할 일
1. r1 → r2 차이를 2a-01(데스크톱)과 2a-06(모바일)에 대해 확인하고 SPEC 1.2·1.3의 해당 행을 고친다. 모바일(2a-06)이 바뀌었는지도 원본으로 확인해 명시한다.
2. **4.2 카탈로그를 r2 기준으로 다시 쓴다.**
   - 필터 9종(FR-CAT-01)을 레일에서 어떻게 모두 제공할지: r2 레일은 타깃·콘셉트·레이아웃·목적·라이선스 + 모션만 그린다. 업종(칩 줄 유지 여부)·색상·디바이스를 어디에 둘지 결정. 기존 FilterRail 구조를 최대한 재사용해 **코드 변경·번들을 줄이는 쪽**을 우선한다.
   - 그룹 옵션의 개수 표시("20~30대 5")를 넣을지: 넣는다면 계산 기준(현재 결과 기준 facet count)과 접근 이름 규칙.
   - "초기화 · N" 버튼: N의 정의, 기존 "필터 초기화" 접근 이름과의 관계.
   - 그리드: ≥1280 3열 기준으로 반응형 단계를 다시 정한다(레일 220 + 간격 포함 가용 폭 근거).
   - 모바일(<768): 레일을 어떻게 접는지("필터 N" 패널 유지 여부).
3. facet 팝오버 설계(C-01, V2-AC-17·18)는 폐기 또는 대체한다고 명시하고, 4.5 충돌 표·5절 B-4(새 컴포넌트·번들)·6.1 V2-2a 범위·6.2 수용 기준(V2-AC-17~19·26 등)·6.3 깨질 테스트 표를 r2 기준으로 갱신한다. AC ID는 재사용하지 말고 바뀐 AC는 `V2-AC-17r2`처럼 표기하거나 새 번호를 이어서 붙인다(삭제는 "폐기"로 남김).
4. SPEC 머리에 "개정 r2" 항목을 추가하고, 7절의 r2 메모를 "반영 완료"로 고친다. 새 설계 질문이 있으면 7절에 Q8부터 추가(추천안 포함).
