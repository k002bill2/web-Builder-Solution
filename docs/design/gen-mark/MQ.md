## MQ-GM-1 카드 출처 Tag 위치 (썸네일 겹침 해소)

사실: 라이선스 Tag(썸네일 안 우상단)·"생성 조합" Tag(그 아래)가 실렌더 header의 내비·우측 CTA를 덮는다(`ReferenceCard.tsx:53-57·118-123`, 실화면 `shots/01-catalog-1280.png`·`02-catalog-390.png`). 최소 카드 폭 ≈296px, Tag 2개 ≈110~120px(추정).

| 선택지 | 내용 | 트레이드오프 |
|---|---|---|
| **★A** | 두 Tag를 썸네일 **밖, 제목 위 "출처 줄"**로 | 겹침 0 · 상세 머리(제목 + Tag)와 같은 위계 · 반투명 받침 불필요. 대가: 모든 카드 높이 +≈28px(추정), 테스트 1건(181행) 뒤집기 |
| B | 두 Tag를 맨 아래 **팔레트 줄**(팔레트 ●●● 옆, 저장·비교 버튼 왼쪽)로 | 카드 높이 0 증가. 대가: 정보(출처)와 조작(버튼)이 한 줄에 섞임 · 위계가 가장 낮아 권리 정보가 눈에 덜 띔 · 296px에서 여유 ≈60px(추정)로 빠듯 |
| C | 썸네일 안 유지, **좌하단으로 옮기고** 받침 불투명 | 카드 구조 변화 최소. 대가: 실렌더 본문(히어로·섹션)을 대신 덮음 — 겹침 "이동"이지 해소 아님, 목업 위치와도 다름 |

근거 한 줄: 썸네일은 첫 화면 구조(CTA 위치 = 비교 축)를 보여주는 자리라 그 위에 아무것도 얹지 않는 A만이 문제를 없앤다.

## MQ-GM-2 상세 화면 출처 표식 형태

사실: 상세 머리 = h1 + 라이선스 Tag, 출처는 메타 줄 끝 `buildNote`("internal 조합 생성기 internal-compose-1으로 조립")뿐(`ReferenceDetailPage.tsx:42-55`, `internalCompose.ts:189`). 생성·큐레이션 모두 `internal`이라 라이선스 Tag로는 구분 불가.

| 선택지 | 내용 | 트레이드오프 |
|---|---|---|
| **★A** | "생성 조합" Tag(카드와 같은 부품) **+ 설명 한 줄** "섹션 라이브러리를 조합 규칙으로 자동 생성한 레퍼런스입니다." | 카드와 같은 말 + 처음 보는 사용자에게 뜻을 풀어줌. 대가: `/references/:id` 첫 화면 +0.08~0.15KB(추정, 여유 2.68 안) |
| B | "생성 조합" Tag만 | 카드와 완전 동일·최소 변경. 대가: "생성 조합"의 뜻은 여전히 내부 용어 buildNote에 기대야 함 |
| C | Tag 대신 메타 줄 `buildNote`를 사람 말로 교체 | 문장 하나로 해결. 대가: 생성기 데이터 변경 → G5 해시 갱신·생성기 레인 영역 침범, 카드와 표식 불일치 |

근거 한 줄: 상세는 카드보다 공간이 있고 "왜 미측정인지"의 맥락이 필요한 곳이라 Tag(일관성)와 한 줄(이해)을 같이 둔다.

## MQ-GM-3 카드 라이선스 Tag 스크린리더 낭독

사실: 지금 카드 라이선스 Tag는 `aria-hidden`이라 카드에서 라이선스가 **읽히지 않는다**(`ReferenceCard.tsx:53`, 테스트 `ReferenceCard.test.tsx:181`). 상세에서는 읽힌다(`ReferenceDetailPage.tsx:48-50`).

| 선택지 | 내용 | 트레이드오프 |
|---|---|---|
| **★A** | 썸네일 밖으로 나오면서 읽히게 + sr-only 접두 "라이선스"(Tag 밖 형제) → "라이선스 internal" | 카드·상세 낭독 일치, 권리 경계(PRD 원칙 4) 정보 전달. 대가: 카드당 낭독 1~2단어 증가 × 21장 |
| B | 읽히게 하되 접두 없음 → "internal" | 가장 단순. 대가: 영문 단어 하나만 들려 뜻이 모호 |
| C | 지금처럼 `aria-hidden` 유지 | 낭독 변화 0. 대가: 시각 사용자만 라이선스를 앎(화면 밖으로 나온 뒤엔 숨길 근거가 사라짐) |

근거 한 줄: 숨긴 이유(그림 안 장식)가 위치 이동으로 사라지므로, 시각과 같은 정보를 최소 단어로 준다.
