## 현재 vs 시안 (Jarvis 대조, 이것이 수용 기준)
1. **2단 비율**: 현재 왼쪽이 약 절반(`ProfilePage` `5fr/7fr`). → 1280 이상에서 왼쪽 약 340(`--spacing(85)` 수준, ±20), 오른쪽 나머지. 1024 이하 기존 한 열 흐름 유지.
2. **왼쪽 패널 = 요약 우선**: 헤더(프로필 이름·버전 배지·확정 시각) → 핵심 값 요약(대표색 스와치·폰트·밀도 등 짧은 목록) → 대비 검사 **요약 1줄**(통과/미달 개수) → 조정 영역. 프로필 값 13줄 전체 목록·대비 5줄 상세는 **"값 전체 보기"/"대비 상세"** 디스클로저로 기본 접힘. 저장·버전·보정 흐름과 A11Y 동작 불변.
3. **패널 제목·배지**: 패널 h2 `ds-heading1`, 현재 버전 배지 violet 톤(글자 "현재" 유지). 링크 `text-primary` → `text-primary-text`(프로필 영역 한정) + 링크 대비 가드 테스트.
4. **3안 카드 = 시안처럼 간결**: 카드 기본 노출은 와이어프레임 + "A안" + 설명 2줄(축 요약) + 선택 상태. 로그 3줄·lint 경고 상세·결과 해시·"섹션 순서 보기"·"전체 로그"는 카드 안 **"상세" 디스클로저 1개**로 접는다. lint 경고가 있으면 접힌 상태에서도 "경고 N" Tag는 보인다(색 단독 금지). 선택 버튼 `aria-pressed`·접근 이름 "A안 선택" 불변.
5. **편집 시작 위치**: "B안으로 편집 시작"과 편집 미구현 안내를 **카드 바로 아래 오른쪽**으로. 3안 비교 표는 그 아래 **"3안 비교 표 보기"** 디스클로저(기본 접힘, ≥768에서만 제공, 390/320 숨김 유지).
6. 생성 중/부분 실패/전체 실패/재시도/저장 안 된 조정 차단/이전 버전 복원 — 상태·알림(`role=status`/`alert`)·포커스 동작 전부 불변.
