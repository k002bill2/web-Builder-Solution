## MQ-F0 — 참조 집합 규칙: 필드 입력 뒤에도 삭제한 섹션의 이미지를 붙잡을까 (B-ER-08 핵심)

- [사실 L1] 지금 필드 글자는 기록 밖이라 "삭제 → 글자 1자"에서 사슬이 끊기고 이미지가 놓인다 — `undoStack.ts:27-29,55-59` · `StudioLayoutImages.test.tsx:111-128`.
- [사실 L1] 필드 글자를 기록에 넣으면(MQ-R5 ★A, 결정 `docs/design/editor-rest/MQ.md:75`) 삭제 전 문서가 Ctrl+Z 2회로 닿는다. 놓인 이미지는 되살릴 수 없다(`StudioLayout.tsx:307-308`).

| 선택 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A ★** | 참조 집합은 기록을 따른다 — 필드 입력은 이미지를 놓지 않는다. 테스트 단언 2건을 SPEC 6절 문장으로 바꾸고 무효화 단언은 진짜 끊김 경우로 옮긴다 | U1(모든 "넣음" 연산 되돌리기) 충족 · 되돌린 섹션에 이미지 그대로 · 데이터 손실 0 | 이미지 메모리를 기록이 쥐는 만큼 더 오래 쥔다(상한 50 · 언마운트에 해제) |
| B | 필드 기록 앞에서 사슬을 끊는다(필드 기록 = 그 이전 기록 무효화) — 단언 유지 | 테스트 문장 변경 0 · 메모리 빨리 해제 | 글자 1자만 쳐도 앞의 섹션 삭제를 되돌릴 수 없다 — MQ-R5 ★A 의도(실수 복구)와 2a-05 5.14 "최대 50" 위반 |
| C | 필드 기록은 닿게 하되 이미지는 놓는다(단언 유지) | 테스트 문장 변경 0 | Ctrl+Z 2회로 돌아온 섹션의 이미지가 비어 있다 — 기능 결함(ER-AC-U1 위반) |

## MQ-F1 — 멈춤 없이 길게 친 입력을 쪼갤까

- [사실 L1] ER 3.5 `:143` "blur 또는 600ms 멈춤에 1건" · 자동 저장 2초 디바운스 · 최대 30초(2a-05 `:326`).
- [추정 L3] 600ms 멈춤 없이 30초 넘게 치는 경우는 드물다(붙여넣기는 입력 1회).

| 선택 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A ★** | 쪼개지 않는다 — 멈춤·blur·키 변경·다른 기록만 경계 | 규칙 단순 · 타이머 1개 · ER-AC-U3 문장 그대로 | 아주 긴 연속 입력은 한 번에 되돌아간다 |
| B | 묶음 시작 뒤 30초(자동 저장 maxWait와 같음)면 강제로 닫는다 | 긴 입력 부분 복구 | 타이머 2개 · 청크 증가 [추정 +0.05] · 경계가 사용자 행동과 무관한 시점에 생김 |

## MQ-F2 — 다른 섹션의 필드 기록을 되돌릴 때 그 섹션을 선택해 보여줄까

- [사실 L1] 지금 실행 취소는 선택·탭·포커스를 바꾸지 않는다(`opAfter.ts:61-63`). 390은 캔버스가 다른 탭이라 변화가 안 보일 수 있다.

| 선택 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A ★** | 바꾸지 않는다 — 알림이 "{섹션 이름} {필드 라벨} 편집"으로 무엇이 돌아갔는지 말한다 | 섹션 연산과 같은 규칙 · 포커스 이동 0(키보드 사용자 위치 유지) · 진입 증가 0 | 390 "편집" 탭에서 다른 섹션 값이 바뀐 것을 눈으로는 바로 못 본다 |
| B | 그 섹션을 선택(1280·1024 편집 패널 전환 · 390 "편집" 탭 유지)하고 포커스는 그대로 | 바뀐 칸이 바로 보인다 | 실행 취소마다 편집 패널이 바뀌어 연속 Ctrl+Z 때 화면이 튄다 · 선택 상자 스크롤 재측정(B-ER-11 계열) 회귀 위험 |

## MQ로 보내지 않은 것 (참고)

- 600ms 값 · blur 경계 — ER 3.5 결정(MQ-R5 ★A) 그대로.
- 입력칸 안 Ctrl+Z = 브라우저 기본 — ER-AC-U2 그대로.
- IME 조합 중 경계 없음 — 반쪽 자모 기록을 막는 데 다른 합리적 안이 없다(SPEC 4.6).
- 탭 간: 기록은 탭 로컬 · 읽기 전용 탭도 동작 — P1C 1.5 "편집은 메모리에서 계속 됨"(`docs/design/persistence/P1C-SPEC.md:82`)에서 바로 따라온다.
- 문구 — 기존 형식("실행 취소: …") 재사용, 새 문장 0.
