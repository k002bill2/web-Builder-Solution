# ADR-009 — 제품 범위 전환: 사이트 디자인 샘플 추출 전용

- 상태: **채택** (영환님 2026-10-25 Slack: "다른 사이트를 구축하고 호스팅서비스까지 하지 말고 사이트 디자인 샘플을 추출하는 기능으로만 사용") · 문안 Jarvis
- 범위 선택(같은 날 clarify): 추출 경로 = **내부 + 외부 URL 둘 다** · 기존 구축 기능 = **유지** · 보존 태그 원격 push = **승인**
- 대체: ADR-008(호스팅) → **폐기**. M5(발행) 전체 중단.
- 보존 지점: 태그 `archive/20261025/builder-full-m4` → `7654a129`(main, PR #68 · M1~M4 완료 · M5 미착수). 원격 `origin`에 push 완료(2026-10-25).

## 1. 결정

1. **제품 목적 전환**: "레퍼런스 → 디자인 프로필 → 홈페이지 생성·내보내기·발행" → **"사이트 디자인 샘플 추출"**. 제품은 고객 사이트를 만들어 운영하거나 호스팅하지 않는다.
2. **디자인 샘플의 정의**(산출물): 렌더된 시안 이미지(PNG) · 시안 열람용 정적 HTML · 디자인 토큰(색·글꼴·간격·제목 비율·모서리·모션 프리셋) · 섹션 구성. 정확한 포맷(토큰 파일 스키마 등)은 SAMPLE-SPEC에서 정한다.
3. **추출 경로 2개**
   - **A. 내부 경로 (구현됨)**: 레퍼런스 탐색 → 디자인 프로필 → 3안 실렌더 → PNG·정적 HTML 내보내기. 현행 코드 그대로 쓴다. 남은 일 = 토큰 내보내기 형식 확정·화면 문구를 "샘플" 관점으로 정리.
   - **B. 외부 URL 경로 (신규 · 미착수)**: 사용자가 입력한 사이트 URL에서 디자인 특징(색·글꼴·레이아웃)을 추출. **2절 정책 게이트를 통과하기 전에는 코드 착수 금지.**
4. **사이트 구축 기능 = 유지·동결**: 섹션 편집기·스냅샷·React zip·정적 zip의 코드와 화면을 지우거나 숨기지 않는다. 신규 기능 투자는 중단하고 회귀·보안 수정만 한다. 되살릴 기준점은 위 보존 태그.
5. **하지 않는 것**: 발행·서브도메인·롤백·미리보기 공유(FR-PUB-04~06) · 호스팅 계정·DNS·결제 · 발행 서버(M5-SCOPE 1.3 S1~S6).
6. **공개 카피 금지**: "홈페이지 만들기", "발행", "호스팅", "바로 운영" 등 사이트 구축·운영을 약속하는 표현.

## 2. 외부 URL 경로(B) 정책 게이트 — 착수 전 모두 충족

현행 정본은 외부 URL 수집을 막고 있다. 이 ADR은 그 금지를 **스스로 풀지 않는다**. 아래 조건을 SPEC·법무·보안 검토로 확정한 뒤 별도 결정으로 해제한다.

- 충돌하는 현행 정본(그대로 유효): `docs/02-prd/PRD.md` L39(GDWEB 수집 금지) · L41(외부 URL 스크린샷 수집 MVP 제외, 도입 시 robots·약관·법무·비공개·생성 입력 금지) · L166 비목표("임의 웹사이트 전체 복제", "외부 URL 스크린샷 수집") · `docs/03-trd/TRD.md` L238(`external_observed` 조건, GDWEB 영구 제외) · TR-POL-02(제3자 갤러리 자동 수집 코드 금지, UA 위장 금지).
- 게이트 조건 초안:
  1. **대상**: 사용자가 직접 입력한 단일 URL, 요청 1회. 링크 추적·크롤링·갤러리 대량 수집 금지. GDWEB·dbcut 영구 제외.
  2. **허용 확인**: robots·이용약관 확인, UA 위장 금지, 로그인·유료 영역 접근 금지.
  3. **추출물 범위**: 추상 특징만 저장(색 팔레트 값·글꼴 계열 이름·간격 리듬·섹션 구조 태그). 원본 이미지·로고·본문 텍스트·HTML/CSS 원문은 저장·재배포·생성 입력에 쓰지 않는다("임의 웹사이트 전체 복제" 비목표 유지).
  4. **실행 위치(기술 제약)**: 브라우저 단독 앱은 교차 출처 정책 때문에 다른 사이트의 DOM·CSS를 읽을 수 없다 [추정 — 설계 검토로 확인]. 서버 측 fetch 또는 로컬 헤드리스 도구가 필요하며, 서버를 두면 ADR-007 P7(서버는 별도 ADR)을 발동한다. 서버 fetch는 SSRF 방어(사설·메타데이터 IP 차단, 리디렉션마다 재검증, 시간·크기 상한)·쿠키/개인정보 제거가 필수다.
  5. **법무**: 디자인 특징 추출·표시의 저작권·약관 리스크 판단(Newton 조사 → 법무 확인). 확인 전 공개 기능으로 내지 않는다.

## 3. 영향

- **ADR-008**: 폐기. 문서·원장(`dev/active/m5-scope/HOSTING-LEDGER.md` · `HOSTING-LEDGER-D.md`)은 기록으로 보존. Cloudflare 문의(10-21 제출)는 회신이 와도 기록만 한다.
- **M5-SCOPE**(`docs/design/m5/M5-SCOPE.md`): 보관(중단). PUB-AC는 적용하지 않는다.
- **BACKLOG**: 발행 전제 항목(B-M5-01 · B-M4A-09 · B-SEC-09 ③ · B-M4B-01·02·03)은 **동결**(구축 기능 재개 시 부활). 정적 HTML 시안을 Safari·Firefox에서 여는 확인만 "샘플 열람 호환성"으로 남길지는 SAMPLE-SPEC에서 정한다.
- **CI**(`.github/workflows/ci.yml`): 엔지니어링 게이트로 유지. 발행과 무관.
- **PRD·TRD**: 이 ADR이 우선한다. 본문 개정(제품 정의 13행·목표·FR-PUB·비목표)은 후속 작업(PRD v0.4).

2. Designer — SAMPLE-SPEC: 샘플 산출물 포맷(토큰 파일 스키마), 내부 경로 화면 문구 정리, 외부 URL 흐름·상태(차단·실패 포함).
3. Security — 외부 fetch 위협 모델(B 게이트 4).
