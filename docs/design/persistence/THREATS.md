# PERSIST THREATS — 추천안(ADR-007 초안 ★: IndexedDB 로컬 + 파일 묶음) 위협 목록

- Security 레인 입력용 초안. [L1] 코드 확인 · [L3] 외부 일반 지식(확인 필요) · [추정].
- 범위: P1(IndexedDB)·P2(파일 묶음). 서버(P3)는 별도 ADR에서 위협 모델을 새로 쓴다.

## 자산

| ID | 자산 | 위치(추천안) |
|---|---|---|
| A1 | 사용자 업로드 이미지(사진 — 인물·사업장 등 개인정보 가능) | IDB `images` · 내보낸 파일 |
| A2 | 문서 텍스트(상호·연락처·사업 설명) | IDB `docs`·`snapshots` · 내보낸 파일 |

## Security 레인에 넘길 확인 항목

1. `allow-same-origin` 금지 가드 테스트 존재 여부(없으면 추가 제안).
2. 배포 CSP 초안(스크립트 출처 고정) — 배포 ADR과 함께.
3. Web Locks·`storage.persist()`·축출 정책의 대상 브라우저별 실제 동작(L3 → 확인).
4. 데이터 지우기가 IDB·캐시·object URL을 모두 비우는지 실측 기준.
