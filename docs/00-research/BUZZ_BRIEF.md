## 1. 목적
GDWEB 선정작에서 반복되는 **디자인 패턴(레이아웃·섹션·스타일·인터랙션)** 을 체계화해,
사용자가 업종·목적·스타일을 고르면 홈페이지를 조립·생성하는 솔루션을 만든다.
이번 분석 결과는 이후 Hermes 팀(Designer·Developer·Security·QA 등)이 PRD / TRD / 개발계획서를 작성하는 입력이 된다.

## 3. 공통 규칙
- 각 결과는 **결론 → 근거(URL·화면 관찰) → 사실/추정/확인 필요 구분 → PRD/TRD에 넘길 요구사항 후보(번호 목록)** 순서.
- 특정 선정작 디자인을 그대로 복제하는 방안은 제안하지 않는다. 패턴은 추상화된 구조·규칙 수준으로 정리한다.
- GDWEB 페이지는 **읽기 전용 관찰**만 한다. 로그인·회원가입·스크랩·심사등록·대량 크롤링 금지.
- 외부 발송·게시·Git 원격 쓰기 금지. 파일 쓰기는 위 산출물 경로에만 한다.
- 스레드 답글은 핵심 요약(요구사항 후보 포함) 1건, 상세는 산출물 파일로 남기고 파일 경로를 답글에 적는다.
