- [사실] 목업에는 **프로젝트 목록 화면이 없다**(7개 화면: 카탈로그·상세·비교 보드·프로필·생성·편집기·모바일 카탈로그·모바일 편집).
- [사실] 목업의 "프로젝트" 메뉴는 2a-04에서만 활성이다(186행). 즉 목업 기준으로 "프로젝트" = 프로필·생성 한 장이다.
- [사실] SPEC r6 2.1은 "GNB 새 프로젝트 → /profile (프로필 목록 · 없으면 시작 안내)"로 정했고, 구현도 같다.
- [추정] 편집기 헤더의 프로젝트 이름, TRD `generated_project`, ADR-005 Q1("확정 시 프로젝트를 만들거나 골라")을 합치면, **"프로젝트"는 프로필 계열 + 편집 문서 + 발행을 묶는 단위**다. 지금 IA에는 이 단위를 만들고, 이름 붙이고, 고르는 화면이 없다.
- 결론: 설계 질문 **Q1(프로젝트 목록·엔티티)·Q2("새 프로젝트" 동작)**로 넘긴다.
