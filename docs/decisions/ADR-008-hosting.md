## 2. 비용 충돌 (보류 사유)

- WfP 유료 시작가 **$25/월**(R2 별도) [28] > 상한 $10. 일반 Workers Paid는 **$5/월 최소**(계정당) [19] + R2 종량(무료분 10GB-월·Class A 1M·B 10M [21])이라 상한 안이다.
- 그러나 일반 Workers 약관은 접근권 판매·제3자 대리 가입을 금지하며(self-serve §2.2.1(a) [29]), End Users 예외는 WfP 특약 §10에만 명시돼 있다 [30]. 원장은 이 예외를 일반 $5 Workers로 넓히지 않는다(원장 L340).
- 따라서 **$10 안의 구성(일반 Workers Paid + R2)이 우리 사용 형태에 허용되는지는 Cloudflare 서면 회신으로만 판정**한다. 회신 전에는 어느 구성도 고르지 않는다.

## 3. 회신에 따른 분기 (미리 정함)

1. 회신 = **"일반 Workers Paid + R2로 허용"** → 구성 = $5 Workers Paid + R2. 이 ADR을 그 구성으로 고치고 M5-b PoC 착수(계정 생성·결제는 영환님).
2. 회신 = **"WfP 필요"** → 상한 $10과 충돌. **상한 재질의**(★ = $25+R2로 상한 상향 vs 후보 재검토). M5-b 착수 안 함.
3. 회신 없음·모호 → 보류 유지. 다른 후보(M5-SCOPE 3절 B·C)로 조용히 바꾸지 않는다.

## 4. 보류 해제 조건 (모두 충족 → 채택)

1. **약관 서면 회신**: 위 3절 1 또는 영환님이 승인한 대안 구성에 대한 사업자 서면 확인(이메일 원문을 `dev/active/m5-scope/`에 보관, 개인 정보·계정 ID 가림).
2. **미리보기 24h 우회 차단**: M5-d 종료 기준(PUB-AC-11~14) — 만료 +1초 뒤 HTML·CSS·JS·이미지·글꼴 모두 거부, 원본 저장소 직접 URL 거부, 캐시 예열 후 만료·폐기 거부.
3. **발행 p95 ≤2분 · 롤백 ≤1분 실측**: M5-SCOPE 2.1 정의(외부 관측 기준, 표본 측정 전 고정) · PUB-AC-04~06.

## 5. 금지 (이 ADR이 보류인 동안)

- **M5-b PoC 착수 금지**(코드·계정·DNS·결제 0). M5-0 릴리스 체크·M5-a CI는 이 ADR과 독립이라 진행 가능.
- 공개 카피에 "발행 2분/롤백 1분 보장" · "24h 뒤 자동 비공개" · "무제한 무료" 금지(M5-SCOPE M5-c).
- R2 공개 도메인을 열지 않는다 — Worker binding으로만 읽는다(M5-SCOPE 후보 A [22]).
