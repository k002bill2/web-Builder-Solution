## 1. 범위 (이 5건만)
1. **D-V22-01 주 메뉴·로고 포커스 링** — 로고·주 메뉴 링크에 v2 2중 링(`--focus-ring` 토큰, 기존 DS 링 유틸 재사용)을 적용하고, 링이 `nav`의 `overflow-x-auto`에 잘리지 않게 한다(예: 스크롤 영역 안쪽 여백/`md:` 이상에서 overflow 해제 등 — 방법은 판단). 1280·390 모두 링 4면이 보여야 한다.
2. **D-V22-02 "초기화" 후 포커스 유실** — 키보드·클릭으로 초기화한 뒤 포커스가 body로 가지 않게 한다. 목적지는 레일 안의 합리적 위치(예: 레일 제목 또는 첫 그룹; `tabIndex=-1` 제목 허용). 스크린리더가 결과를 알 수 있게 기존 live region이 있으면 재사용.
3. **D-V22-03 390 업종 칩 잘림** — Tab으로 포커스한 칩과 링이 칩 스크롤 영역 안에 완전히 보이게 한다(예: `scroll-padding-inline`/`scrollIntoView({block:'nearest',inline:'nearest'})` + 링 여백). 마우스 동작은 바꾸지 않는다.
4. **D-V22-04 "N 개" 띄어 씀** — 숨긴 설명 노드가 하나의 텍스트 노드로 "N개"/"선택 N개"를 만들게 한다(템플릿 문자열). 테스트는 접근성 이름·설명 문자열을 정확히 비교.
5. **D-V22-05 펼친 필 목록 Tab 도달** — 펼친 뒤 Tab(앞으로)으로 목록에 들어갈 수 있게 한다. 권장: DOM에서 목록을 토글 **다음**에 두고 시각 위치는 CSS로 유지(보이는 순서와의 차이는 2.4.3 판단을 REPORT에 한 줄), 또는 펼칠 때 목록 첫 항목으로 포커스 이동 중 하나를 골라 근거를 적는다. D07(빼기 후 포커스)·Esc 복귀·한도 알림은 그대로 통과해야 한다.
