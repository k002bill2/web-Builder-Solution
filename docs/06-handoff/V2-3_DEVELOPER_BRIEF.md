## 1. 범위 (SPEC 4.3 그대로)
1. **탭 삭제 → 2단 레이아웃**: 왼쪽 미리보기 패널 + 오른쪽 정보 패널(h1·섹션 구성·토큰 요약·점수·태그·저장/비교/템플릿). <1024 한 열. DOM 순서 = 보이는 순서(뒤로 → 미리보기 폭 → 미리보기 → 정보 패널 → 아래 영역).
2. **미리보기 폭 전환**: SegmentedControl radiogroup "미리보기 폭"(데스크톱·태블릿·모바일), URL `view`(기본 desktop 생략), **옛 `?tab=mobile` → `view=mobile`로 해석**(북마크 호환). 모바일 선택 시 모바일 와이어프레임 + 기존 모바일 구조 설명. 390에서 h1이 첫 화면 안에 들도록 모바일 미리보기는 16:9.
3. **정보 패널**: 섹션 구성(순번 `label-alternative`), 토큰 요약(견본 4칸 `role=img` + hex 목록 + 한 줄 요약 — 기존 TokensPanel 간격·모션 값은 한 줄에 합침), 점수 3칸(`text-status-*-text`, 700).
4. **태그 비대화형**(C-11): 콘셉트·목적 태그는 버튼이 아니다 — 기존 Tag 컴포넌트.
5. **저장·비교·템플릿**: 정보 패널 하단. "비교 중" = **outline 유지 + `check` 아이콘 + 글자 "비교 중"**(접근 이름 "비교 중, 비교에서 빼기" 그대로), 저장 = outline + `bookmark-fill` + `aria-pressed`. D-QA06 알림 + "보드 열기" 형제 링크(A11Y-AC-17).
6. **아래 영역(전폭)**: "유사 레퍼런스" 3그룹(각 ≤ 6, 이름 2줄 B-DET-02) + "점수 이력" — **유지**(C-07, FR-CAT-03 P0).
7. **`Tabs.tsx` 삭제**: 카탈로그는 V2-2에서 이미 빠졌고 상세가 마지막 사용처다(grep 확인). 상세에서 빼면 `components/ds/Tabs.tsx`와 그 테스트를 지운다(B-4).
8. 합격 기준: **V2-AC-27·28·29·30·31·38·39**. 깨지는 기존 테스트는 SPEC 6.3 표(`ReferenceDetailPage.test`, `keyboardA11y.test`의 "상세 보기" tablist) 안에서만 고친다 — 목록 밖 테스트가 깨지면 멈추고 사유 기록.
