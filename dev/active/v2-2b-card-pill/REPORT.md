## 4. 목업과 다르게 한 곳 (SPEC 4.5)
- **C-03**: 카드 제목 2줄(`line-clamp-2`), 목업은 1줄 말줄임.
- **C-04**: 캡션 2줄("업종 · 레이아웃 · 모션", "태그 · 태그 · 반응형") + 라벨 있는 점수 줄·측정일. 목업 "96 / 92"는 라벨이 없음. 라벨이 붙어 길어져 점수 줄을 제목 오른쪽이 아니라 캡션 아래 한 줄로 옮겼습니다.
- **C-05**:
  - 펼침 버튼 글자는 "비교 보드 N / 6"(목업 "비교 N / 6")입니다. 6.3 밖 `trayBoard.test`의 계약 때문이고, sr-only로 "보드"만 끼우면 2.5.3에 걸려 보이는 글자에 넣었습니다.
  - 목업에 없던 것을 더했습니다: 빼기 목록, 한도 말풍선, 0개일 때 필 유지, Esc·포커스 이탈 시 닫기.
  - 브리프의 "`secondary` 역상 변형"은 쓰지 않았습니다. 펼침 버튼은 목업처럼 필 면 위의 글자이고(`secondary`는 흰 12% 면을 깔아 필 안에 칩이 하나 더 생김), hover에만 `inverse-fill-normal`을 씁니다. 역상 자식은 전부 `on-surface-inverse`·`inverse-*` 토큰이고 대비는 SPEC 3.3 표(흰 .12·.16 면 포함 최저 5.77)의 범위 안입니다. 이 필에는 `secondary`로 바꿀 채움 버튼이 없어 V2-AC-11 가드와도 충돌하지 않습니다.
- **C-12**: "/ 6"을 opacity .5 대신 `inverse-label-alternative`로 칠했습니다.
- 그 밖:
  - 대표색 점은 <640에서 숨겼습니다(390 필 폭 확보, 목업 2a-06 모바일 필에도 없음).
