## E4 재현 확인 (차단 해제 뒤, 같은 페이지)
- 첫 시도: 차단을 별도 스크립트에서 걸어 세션 종료로 풀림 → RecoView 200 수신(절차 오류, 앱 결함 아님) → 한 스크립트 안에서 차단·조작·해제로 재실행.
- page 안 import('/assets/RecoView-CpMYkhU4.js') → reject "Failed to fetch dynamically imported module" · 새 요청 0
- import('/assets/RecoView-CpMYkhU4.js?bust=1') → ok · 새 요청 1 (200)
- "다시 시도" 2회째 클릭 → alert 그대로 · 카드 0
- "다시 시도" 클릭 직후 포커스 BODY(alert 제거 → 스켈레톤, 포커스 대상 사라짐)
