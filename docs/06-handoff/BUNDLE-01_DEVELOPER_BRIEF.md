## 2. 질문 (답해야 할 것)
1. 공통 JS(모든 라우트 첫 화면에 들어가는 청크)의 **모듈별 gzip 기여 상위 20개** — manifest + 소스맵(또는 rolldown/vite 출력 분석)으로 실측.
2. React 코어 분리의 **원인**(Vite 8 / rolldown 기본 청크 규칙인지, 특정 import 패턴인지)과 청크 경계 오버헤드(청크 하나당 래퍼·import 문 바이트) 실측.
3. **회수 후보**를 효과(KB)·위험·변경 범위로 표 작성. 예: 청크 규칙 설정(advancedChunks/manualChunks 등 현재 Vite 8에서 지원되는 방식 — 공식 문서 확인), 공통에 있지만 첫 화면에 불필요한 모듈(`Icon.tsx` eager glob 등 B-3)의 지연 로드, 라우트 전용으로 내릴 수 있는 공용 컴포넌트, 압축 설정(minify 옵션) 등.
4. `/compare`가 V2-4 전에 확보 가능한 여유 **추정 범위**와 권고안 1개(+ 대안 1~2개). 예산(ADR-004) 조정은 권고안이 아니라 마지막 대안으로만, 근거와 함께.
