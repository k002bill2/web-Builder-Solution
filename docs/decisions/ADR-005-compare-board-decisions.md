# ADR-005 — 비교 보드(1a-03) 설계 질문 Q1~Q6 결정

- 상태: **승인** (영환님, 2026-09-25 Slack 선택 1 — Designer 제안 채택)
- 근거: `docs/design/1a-03/SPEC.md` 11절

| # | 질문 | 결정 |
|---|---|---|
| Q1 | 보드의 소유 (TRD `compare_board.project_id`, 비교 시점엔 프로젝트가 없을 수 있음) | MVP는 **사용자당 현재 보드 1개**. 프로필 확정 시 프로젝트를 만들거나 골라 `project_id`를 붙인다. TRD 4.5 개정 대상 |
| Q2 | R-03·R-04(목적별 필수 섹션) 목적 입력 위치 | 보드에서는 검사하지 않는다. **1a-04(프로필)에서 lint** |
| Q3 | 확정(v1) 이후 보드 재선택 | 허용. 다시 확정하면 **새 버전(v2…)**, 이전 버전 불변 (FR-PRF-03) |
| Q4 | 폰트 허용 목록 | 초안: **Pretendard · Noto Sans KR · Noto Serif KR** (OFL). 라이선스·웹 배포 조건은 Newton 확인 후 확정 — 확인 전에는 Pretendard만 활성 |
| Q5 | `selection_mode`를 DesignProfile에 추가 | **추가** (`template` / `mix`). TRD 4.3 개정 대상 |
| Q6 | 회수된 레퍼런스로 이미 확정한 프로필 | 이 화면 범위 밖. **1a-04에서 "출처 회수됨" 표시** |

## 추가 결정 (M1-UI-03a 질문, 영환님 2026-09-25 Slack 선택 1)

| # | 질문 | 결정 |
|---|---|---|
| D1 | 레퍼런스 폰트 행에서 라이선스 미확인 폰트(Noto Serif KR 등) 선택 | Newton 확인 전에는 **선택 불가**. 셀에 "라이선스 확인 중" 표시, 선택 버튼 없음(AC-26과 같은 처리). 사용자 입력 허용 목록과 같은 기준 |
| D2 | R-12: 사업자정보 없는 Footer를 고른 채 확정 | **확장 변형 자동 교체 유지.** 단, 초안 패널 Footer 항목에 "확정 시 사업자정보 확장형으로 바뀝니다"를 미리 표시 |
| D1-갱신 | FONT-01 결과(`docs/00-research/FONT_LICENSE_CHECK.md`, Newton, 2026-09-25) | 3종 모두 **SIL OFL 1.1** — 앱 자체 호스팅·생성 홈페이지 재배포(상업 포함) 허용. 서브셋·변환은 조건부(OFL 유지, 저작권 고지·라이선스 동봉, 수정본이면 RFN 이름 사용 금지 — Pretendard RFN `Pretendard`·`Source`·`Inter`·`M PLUS 1`, Noto Sans KR RFN `Source`). → **허용 목록 3종 모두 활성.** "라이선스 확인 중" 처리는 목록 밖 폰트에만 적용. Noto 폰트 파일의 실제 자체 호스팅(용량·서브셋 방식)은 생성·미리보기 단계(1a-05)에서 결정. 법률 자문이 아닌 원문 확인 |
| D3 | 진입 직후 자동 로드 데이터 청크를 ADR-004 예산에 포함 | **포함하지 않음.** 참고 출력 유지, 실제 API 연결 시 재검토 |

## 구현 분할
SPEC 범위(수용 기준 26개, 새 컴포넌트 8개)가 한 handoff 턴 예산을 넘으므로 둘로 나눈다.
- **M1-UI-03a** — 도메인·데이터 계층(순수 함수·저장소·트레이 통합) + ADR-004 번들 검사 기준 변경. UI 없음.
- **M1-UI-03b** — `/compare` 화면·컴포넌트·반응형·접근성. 03a 완료 후.
