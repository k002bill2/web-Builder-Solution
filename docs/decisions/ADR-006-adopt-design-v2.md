- 상태: 채택 (영환님 2026-09-26 Slack: "디자인이 변경되었어 이 디자인으로 적용해줘", "Design Studio v2.dc.html 다시 적용해")
- 원본: `design/claude-design-handoff-v2/` (README에 출처·잘림 기록)

## 변경 요지 (v2 문서 자체 설명)
"1b 삭제. 1a를 52px 헤더, 흰 배경 단일 표면, 사이드 필터 레일 → 한 줄 칩 필터, 카드 보더 제거(썸네일만 muted 표면), 비교 트레이를 플로팅 필로 축소. 컴포넌트·색·타이포는 새 Dashboard DS 토큰만 사용."
- 화면: 2a-01 카탈로그, 2a-02 상세, 2a-03 비교 보드, 2a-04 프로필·생성, 2a-05 편집기, 2a-06 모바일 카탈로그, 2a-07 모바일 편집
- DS: 주 색 인디고(`--primary` 라이트 #5A5FE8), 녹색 기운 중성색(`--border` rgba(31,54,40,.12), `--caption` #66726A 등), `--muted`·`--card`·`--bg-deep`, 라이트/다크

## 결정
1. v2가 1a를 **대체**한다. 이미 구현한 1a-01~03(카탈로그·상세·비교 보드)을 v2 디자인 언어로 전환하고, 이후 화면(04~07)은 v2 기준으로 만든다.
2. 기존 결정은 유지한다: ADR-002(명칭 금지·중립 브랜드), ADR-003(기능 우선, px 비교 금지), ADR-004(번들 예산), ADR-005(비교 보드 규칙). v2 목업과 기능 결정이 충돌하면 기능 결정이 우선이고, 차이는 SPEC에 사유와 함께 적는다.
3. 토큰은 **우리 이름으로 옮긴다.** 원본 CSS 번들을 앱에 넣지 않는다(Tailwind 유틸리티·차트 30여 색 등 대부분 불필요, 번들 예산). 폰트는 자체 호스팅 유지.
4. DS-A11Y-01(`docs/design/a11y-01/SPEC.md`)의 **방법·배경 집합·가드 테스트 제안은 유지**하고, 토큰 값은 v2 토큰 기준으로 다시 계산한다. 구현은 v2 전환 작업에 합친다(별도 구현 안 함).
5. 순서: Designer 전환 설계(DS-V2-01) → Codex 검토 → Developer 단계 구현(토큰 → 셸·카탈로그 → 상세 → 비교 보드) → QA.
