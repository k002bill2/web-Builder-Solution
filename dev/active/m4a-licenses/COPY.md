## 2. OFL Modified Version·RFN 판단

판단: 원본에서 글자를 추린 서브셋이나 파일 형식 변환본은 OFL 1.1 원문의 Modified Version 정의에 해당합니다. 단, 확장자가 woff2라는 사실만으로 판단할 수는 없습니다. 저작권자가 배포한 Original Version 자체에 woff2가 포함될 수 있기 때문입니다.

- 정의 원문은 원본 구성 요소의 추가·삭제·대체뿐 아니라 “by changing formats”도 수정본에 포함합니다.
- 조건 2는 원본·수정본 모두에 저작권 고지와 라이선스 동봉을 요구합니다. 별도의 “Modified Version” 문구 삽입이나 수정 이력 표시 자체를 독립 의무로 규정하지는 않습니다. 이번 고지 보강은 명세 3절의 필수 필드와 독자 이해를 위한 것입니다.
- RFN은 저작권 고지 뒤에 그렇게 지정된 이름입니다. 모든 원본 계열 이름이 자동으로 RFN이 되는 것은 아닙니다. 조건 3의 제한은 수정본에서 사용자에게 표시되는 주된 글꼴 이름에 적용되며, 해당 저작권자의 명시적인 서면 허가가 있으면 예외입니다. 출처를 밝히는 저작권 고지에서 RFN을 언급하는 것과 주된 글꼴 이름으로 사용하는 것을 혼동하지 않아야 합니다.
- 따라서 현재 ‘Reserved Font Name 고지는 아래 저작권 문장을 따릅니다’는 참조 방향은 맞지만 수정본에서의 이름 사용 조건을 설명하지 못합니다. 교체안은 이 조건을 짧게 풀어 씁니다. 이 문구만으로 실제 글꼴의 RFN 준수가 확인되는 것은 아닙니다.

현재 자료와의 대조:

- `siteFontEmbed.ts:50–55`의 Kit Sans KR·Kit Serif KR 고지에는 원본 이름과 ‘Modified Version’, 서브셋·이름 변경 사실이 이미 있습니다. 각 계열의 `SOURCE.md`에도 서브셋·형식 변환·이름 변경 기록이 있습니다. 기록을 확인했으며 바이너리나 기록의 검사 명령은 재실행하지 않았습니다.
- Pretendard 고지는 저작권과 RFN만 담고 있습니다. 이번에 읽은 자료만으로 실제 동봉본의 원본 대비 변경 여부·변경 주체는 확인하지 못했습니다. 공식 배포 파일을 그대로 동봉하는 경우와 자체 서브셋·변환하는 경우를 구분해야 합니다. ‘동봉한 모든 글꼴은 수정본’이라고 단정하지 않은 이유입니다.
- Pretendard도 자체 수정한 파일이라면, 명세의 원본·수정본 고지 필드와 RFN 사용 조건이 충족되는지 별도 확인이 필요합니다. 전문 블록을 그대로 두는 이번 문안 교체만으로 해결됐다고 보고하지 마세요.
