## 범위 (SPEC 6.1 V2-2 행의 V2-2a 부분)
1. 앱 셸(SPEC 4.1): 헤더 52px, 오른쪽 "새 프로젝트" + 아바타 모든 라우트 동일, 조직 공유 없음, <768 헤더 아래 주 메뉴 한 줄(Q5).
2. 카탈로그 상단(SPEC 4.2 r2): 업종 칩 줄(개수 표시), 정렬 SegmentedControl radiogroup "정렬"(칩 줄에 한 벌), 탭 삭제(보기 = URL `tab`, h1 전환), 본문 `--layout-max-width` 상한.
3. 필터 레일(r2): 기존 `FilterRail` **재사용, 한 벌만 렌더**. 옵션 개수 = 자기 그룹을 뺀 조건의 수(`facetCounts` 순수 함수, 카탈로그 청크에만). "초기화 · N"(Q8: 레일 8그룹만 지움, 업종·정렬·`tab` 유지). <1024 접힘 + "필터 N" 펼침 버튼.
4. 그리드 클래스는 바꾸지 않는다(SPEC 4.2).
