## 목업과 다르게 한 부분 (ADR-003 한 줄 사유) — SPEC 4·5절에 표로 상세

- 카드에서 빠진 필드(태그·반응형·측정일) 유지(FR-CAT-02)
- 상세의 유사 레퍼런스·모바일 구조·점수 이력 유지(FR-CAT-03)
- 비교 보드 템플릿/조합 토글 미채택(ADR-005·1a-03 D-2 유지), 12행 유지(D-3), 조직 공유 숨김(D-1)
- 플로팅 필에 빼기 목록(펼침) 추가 — 트레이 기능·D07 포커스 규칙 유지
