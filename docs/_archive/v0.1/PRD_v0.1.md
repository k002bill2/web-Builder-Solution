# PRD — (가칭) 패턴 빌더: 검증된 웹 디자인 패턴 기반 홈페이지 제작 솔루션

- 문서 상태: **초안 v0.1** · 작성 Jarvis · 2026-09-25 KST
- 근거: `docs/01-synthesis/DISCUSSION_SYNTHESIS.md` (Buzz 토론 합본)
- 관련 문서: TRD `docs/03-trd/TRD.md` · 개발계획서 `docs/04-plan/DEVELOPMENT_PLAN.md` · TDD `docs/05-tdd/TDD.md`
- 요구사항 ID 규칙: `FR-<영역>-<번호>`, 출처 열의 ID는 에이전트 산출물 원 ID(Fable D-n, `PRD-C-nn`, `PRD-E-nn`)

## 1. 배경과 문제

- 에이전시 제작은 수백만~수천만 원이 들어 소상공인·스타트업·기관 실무자에게 부담이다.
- 기존 빌더는 템플릿이 많아 고르기 어렵고, 템플릿을 바꾸면 디자인이 초기화되거나(아임웹 사례, 확인 필요) 결과가 밋밋해 결국 디자인 감각이 필요하다.
- AI 생성 빌더(카페24·Wix·Framer·식스샵)는 빠르지만 결과를 설명·재현하기 어렵고, 한국 업종별 필수 요소와 발행 품질을 보장하지 않는다.
- GDWEB 선정작은 20년간 축적된 "업종·무드·표현" 어휘와 심사 관점(비주얼·정보구성·기술·아이덴티티)을 보여 준다. 이 **관점**을 규칙으로 바꾸면, 비전문가도 선택만으로 수준 있는 사이트를 만들 수 있다.

## 2. 제품 비전

> 업종·목적·무드만 고르면, 검증된 구조와 스타일로 조립된 홈페이지 3안을 받아 비교하고, 섹션 단위로 다듬어 품질 검사를 통과한 뒤 바로 발행한다.

## 3. 목표와 비목표

### 목표 (베타)
1. 비전문가가 가입 후 **15분 안에** 첫 사이트를 발행한다.
2. 발행물이 접근성·SEO·성능 게이트를 **자동으로** 통과한다.
3. 같은 입력이면 같은 3안이 나온다(설명·재현 가능).
4. 구조를 바꿔도 스타일이, 스타일을 바꿔도 콘텐츠가 보존된다.

### 비목표 (베타·GA 공통)
- 제3자 선정작 갤러리 제공, 레퍼런스 URL 모사 기능
- 픽셀 자유 배치·임의 CSS·코드 편집
- 커머스(장바구니·결제), 회원 기능, 블로그 CMS 컬렉션, 다국어 (GA 이후 검토)
- LLM 자유 HTML/CSS 생성

## 6. 핵심 사용자 흐름

```
[가입] → [시작] 업종·목적 선택 + 브랜드명·로고·대표색(선택)
       → [무드] 브랜드명이 들어간 자체 렌더 hero 카드 중 1장 선택
       → [3안] 규칙 기반 3안 나란히 비교 → 1안 선택 (대체안 요청 가능)
       → [편집] 섹션 추가·삭제·순서·변형 교체·슬롯 편집, 전역 슬라이더(밀도·대비·모션), 3개 뷰포트 미리보기
       → [검사] lint 결과(대비·필수 섹션·대체텍스트·모션 예산·SEO·성능)
       → [발행] 서브도메인 발행 → 상태 표시 → 필요 시 롤백
```

## 8. 콘텐츠·권리 정책 (제품 규칙)

1. 제품 어디에도 GDWEB 선정작 이미지·캡처·태그 할당 데이터를 쓰지 않는다.
2. 무드 카드·예시 이미지는 자체 섹션 라이브러리와 라이선스 확보 스톡·폰트만 사용한다.
3. 섹션은 백지에서 새로 디자인하고, 서로 다른 3개 이상 출처의 공통 패턴에 근거할 때만 채택한다.
4. 사용자 업로드 콘텐츠의 권리는 사용자에게 있다. 약관에 명시한다.
