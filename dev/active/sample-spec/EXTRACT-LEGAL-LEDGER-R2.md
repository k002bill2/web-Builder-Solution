# R2 — 외부 URL 디자인 참조·AI 재가공 법무 게이트 근거 원장

보고 대상: Jarvis / 최종 결정: 영환님. 기준·조회일: 2026-10-25 KST.
법률 의견이나 적법성 보장이 아닙니다. ‘사실’은 원문 내용, ‘추정’은 제품 적용 판단, ‘[미확인]’은 증거 또는 구현 확인이 부족한 항목입니다. 출처 내용의 확신과 본 서비스의 적법성 확신을 구별합니다.

## 1. 결론 / 핵심 발견

리스크 등급: 중간 → 중간, 유지. 추상 속성만 AI에 전달하는 제한 경로에 대한 Newton의 정성 판단이며 법무 승인이나 출시 허가가 아닙니다.

1. [추정·중간] ‘참조’·AI 가공·원본 자산 대체는 원본 코드·사진·폰트 파일을 그대로 쓰는 방식보다 직접 복제 위험을 줄일 수 있지만, R1도 이미 독립 레이아웃·새 문구·허가 자산 생성을 전제했으므로 새로 하향할 충분한 변화가 아닙니다.[17][18]
2. [추정·중간] 원문을 클라우드 AI에 넣으면 일시적 복제 외에 공급자 처리 및 입력 권리 보증 문제가 추가됩니다. 본 등급은 원문 입력을 승인하지 않으며, 원문 입력 경로는 별도 법무 게이트 전 차단을 권고합니다.[1][6][9]
3. [추정·중간] 원본을 닮도록 사진·폰트·색상만 치환하면 보호되는 표현·특징적 결합·출처 혼동·성과 무단사용 문제가 남습니다. 독립 재구성의 실질과 최종 결과가 중요합니다.[2][7][18]

### 새 전제에서 가장 큰 위험 3개

- 위험 1 — AI 입력 경로: HTML/CSS/본문/이미지를 ‘참조용’으로 API에 전송하는 순간, 결과에 원본을 남기지 않는다는 조건만으로 처리 단계의 적법성·계약상 입력 권리 보증이 해결되지 않습니다.[1][6][9]
- 위험 2 — 출력의 실질적 유사성: 새 파일·새 문구·AI 생성이라는 외형에도 보호되는 사진 표현이나 창작적인 선택·배열을 재현할 수 있습니다. ‘참조 목적’은 의거관계가 없다는 증거가 아닙니다.[7][17][18]
- 위험 3 — 닮은 외관의 상업 이용: 유사 자산으로 원사이트의 대표적 조합을 유지하면 영업표지 혼동·성과도용 및 자산별 라이선스 문제가 남습니다. 색상 수치만 바꾸는 것은 법정 안전선이 아닙니다.[2][9][15][19]

### ★ 갱신 조건 — 최대 여섯 가지, 모두 정책 권고

★ 1. 접근·허락 유지: 로컬 CLI·허용 목록·단일 페이지를 유지합니다. 소유·관리 또는 추출 및 후속 상업 이용의 허용 근거를 도메인별로 확인하며 사용자 체크만으로 대체하지 않습니다. 기존 접근 제한·차단·우회 금지, GDWEB·dbcut 영구 제외를 완화하지 않습니다. 원문을 외부 AI로 처리할 권리와 후속 자산 사용권까지 허락 범위가 포괄하는지 별도 확인합니다.[6][9]

★ 2. 수집 최소화 유지: 단일 페이지, 순회·자동 재방문·공동 갤러리화 금지, robots 존중 및 중단·누적량 통제를 R1대로 유지합니다. 로컬 실행·참조 의도는 이 조건을 삭제하는 근거로 취급하지 않습니다. 이는 R1의 보수적 제품 정책 유지이며 새 법적 면책 주장이 아닙니다.

★ 3. 저장·모델 입력 수정: 로컬 처리 후 팔레트 값·글꼴 계열명·정규화 간격 범주·통상적 섹션 태그만 허용 스키마로 AI에 전달합니다. 원문 HTML/CSS/본문·이미지·로고·스크린샷·정밀 DOM·좌표·폰트 파일·원본 자산 URL은 결과/로그/캐시 및 외부 모델 입력에서 계속 배제합니다. 모델이 URL을 다시 가져오는 기능도 이 경로에서는 사용하지 않습니다. 원문 입력의 예외는 별도 권리·계약·보관·처리 법무 승인 후 별건 설계로만 검토합니다. 일시적 복제와 폐기 시점은 로컬에서도 확인합니다.[1][6][9][17]

★ 4. 표시·생성 수정: AI 새 시안 생성 자체는 금지하지 않습니다. 원본 화면이나 정밀 구조를 복원하는 입력·프롬프트·템플릿 대신 독립 정보구조·새 문구·다른 시각적 위계를 생성합니다. 동일 섹션 순서·구도·특징적 조합을 재현하려는 목적의 기능은 제공하지 않는 정책을 유지합니다. 일반적인 순서 자체가 항상 위법하다는 뜻은 아닙니다. ‘비슷하게’가 아니라 요구 기능을 기준으로 재설계합니다.[17][18]

★ 5. 고지·중단 유지·보강: ‘참조용/AI 생성’ 표시는 면책으로 광고하지 않습니다. 신고·중단·삭제 절차 및 사용자/운영자 역할을 유지하고, 입력 방식·공급자·검토 결과·허용 근거를 원문 없이 최소 기록하는 정책을 법무 승인받습니다. 보관하지 않는다는 고지는 실제 검증 전 확정하지 않습니다.[1][6][9]

★ 6. 대체 자산·출력 게이트 추가: 상업용 웹 사용·임베딩·수정·납품/재배포 범위에 맞는 사진/폰트 사용권을 확인하고 증빙을 남깁니다. 원사진의 특징적 구도·조명·배치를 재현하는 생성이나 원폰트 파일 변형은 피합니다. 색채상표·브랜드 혼동과 전체 조합의 보호 표현을 사람 검토로 확인하고 의심 결과는 사용 전 보류합니다. 유사도 점수·색상 변경률을 법적 합격선으로 쓰지 않습니다.[2][7][15][18][19]

### 갱신 법무 질문 목록 — 기존 5개 보존 + 신규 2개

Q1. [수정] 로컬 일시 분석 → 추상 속성 기반 AI 추론 → 상업 시안 생성의 단계별로 제35조의2·제35조의5 또는 별도 허락 중 무엇을 근거로 삼습니까? 원문을 외부 API에 넣는 별도 경로는 어느 복제·처리 권한이 추가로 필요합니까? 학습용 TDM 논의를 추론 입력에 적용할 수 있는지도 구분해 주십시오.[1][12]

Q2. [수정] 비회원·로컬 CLI·운영자에 대한 원사이트 약관 성립/편입 및 허용 목록 기준은 무엇이며, 허락이 추출뿐 아니라 클라우드 처리와 후속 상업 이용까지 포함합니까? 실제 API 계약의 입력 권리 보증·배상 조항을 충족할 수 있습니까?[6][9]

Q3. [수정] 팔레트·서체·간격·섹션과 대체 사진의 조합이 보호 표현의 재현 또는 영업표지 혼동·성과 무단사용이 되는 경계를 어떻게 검토합니까? 원본을 보관하지 않으면서 사람 검토 및 독립 재구성 근거를 어느 수준으로 남겨야 합니까?[2][7][18]

Q4. [유지] 사용자별 단일 페이지가 서비스 전체에서 누적될 때 DB 제작자 권리와 현행 (카)/(파)목 적용·누적 통제·중단 기준은 무엇입니까? ‘1 URL’ 안전선을 전제하지 않습니다. R1 질문을 유지하며, 현행 (카)/(파) 구분은 다시 확인했습니다.[2]

Q5. [수정] 미국 제공 시 웹 외관 trade dress의 분류·비기능성·식별력·혼동 및 준거법을 어떻게 판단합니까? AI 변환의 공정이용은 구체적인 상업 사용별로 검토해야 하는지, EU 제공이 추가되면 제3/4조와 현지 이행법·권리유보를 어떻게 적용할지도 분리해 주십시오.[10][16]

Q6. [추가] 대체 사진/폰트/생성 이미지의 실제 라이선스가 웹 공개·임베딩·고객 납품·재배포를 허용합니까? 글자체 디자인권의 통상 사용 예외와 파일 라이선스, 색채상표/화상 디자인권을 별개로 확인하는 절차는 무엇입니까?[13][14][15][19]

Q7. [추가] 확정할 모델·서비스 계약에서 입력 보증, 공급자 보관/학습, 출력 배상과 입력·상표 관련 제외를 어떻게 승인합니까? 원문 입력은 계속 차단하고 추상 속성만 승인할지 먼저 결정해 주십시오.[6][9]

### A. ‘참조’ 목적의 법적 무게

[추정] 목적 설명은 제품의 실제 설계·프롬프트·출력과 일치할 때 의미가 있습니다. ‘참조’라고 쓰면서 원본의 특징적 조합을 유지하게 하면 실질을 바꾸지 못합니다. 의거관계는 원본을 참고했다는 경로와 연결되고, 보호 표현의 실질적 유사성이 별도로 필요하므로 참고 행위 자체도 일괄 금지하지 않습니다.[18]

[추정] 공정이용의 첫 요소만 ‘변형적’으로 주장할 수 있어도 사용량·원작 성격·시장 대체 효과까지 검토해야 합니다. 신상품 시안·경쟁 사이트 외관 제작과 같은 실제 사용 목적을 평가해야 하며 상업성 하나로 자동 탈락하거나 AI 하나로 자동 통과하지 않습니다.[1][16]

- 법안의 ‘안 제35조의5 정보분석’과 현행 제35조의5 ‘공정이용’은 같은 번호여도 다른 내용입니다. 제2208071호의 제안 설명·소위회부 표시를 시행법으로 승격하지 않습니다. 최신 전체 법안의 최종 상태는 별도 한계로 남깁니다.[1][12]
- 2026년 공정이용 안내서 발간은 확인했지만 전문의 해석·사례를 확보하지 못했습니다. 법령이나 확정판결과 동일한 구속력을 가진 TDM 면책 조문으로 취급하지 않습니다.[5]
- ‘AI가 학습하지 않는다’와 ‘제3자 저작물을 입력할 권리가 있다’는 다른 명제입니다. 비학습 안내보다 입력 보증·출력 책임 조항을 함께 읽어야 합니다.[6][9]
- ‘서체 도안이 당시 보호되지 않았다’와 ‘서체 파일에 프로그램 창작성이 있다’는 대상이 달라 충돌하지 않습니다. 디자인보호법 글자체 및 통상 사용 예외도 파일 라이선스와 분리합니다.[11][13][15]
- 현행 성과도용 일반 조항은 (파)목이며 (카)목은 특정 데이터 부정사용입니다. 과거 (카)목 판결의 번호를 현재 UI 성과도용 번호로 그대로 쓰지 않습니다.[2]
- 색채의 저작권상 추상성과 상표상 출처 표시 가능성은 모순이 아닙니다. 사진의 주제와 구체 구도·조명 표현도 나누어 판단합니다.[7][18][19]
- EU 지침 원문 PDF 추출에 제3조 제1항·제4조 제1항 등의 누락이 있어 전문(11)/(18)과 확보된 조문 범위로만 보조 설명했습니다. 국가별 이행법·추론 입력 적용은 검증하지 않았습니다.[10]
- 디자인보호법 검색의 현행 표시는 2025-11-28, 확보한 조문·연혁본은 2025-10-01/2025-11-11로 차이가 있습니다. 제2조/제94조의 확인된 내용만 사용하고 기준일 현행본 완전 대조는 [미확인]으로 남겼습니다.[13][14][20]

## 4. 제외·한계 / [미확인] 목록

1. [미확인] 본 서비스에 제35조의2·제35조의5가 실제 적용되는지, 한국 상업 AI 추론 입력용 특별 TDM 면책의 존재 및 최신 전체 개정안 처리 현황. 확인한 제2208071호 페이지는 소위회부까지만 표시하며 국회 의안 전문/최신 상태와 안내서 전문의 교차검증은 미완료입니다.[1][5][12]
2. [미확인] 실제 입력 원문/추상 속성의 확정 범위, 모델·API·로컬 여부, 공급자 보관/학습 설정·재취득 기능, 로그·캐시·폐기 이행. 코드 없는 설계 단계이며 실험하지 않았습니다.
3. [미확인] 개별 허용 도메인의 약관 성립·편입·허락 범위 및 사용자/운영자 책임 배분. R1 접근·robots·누적 수집 검토를 완화하지 않았지만 관련 약관 전체를 재조사한 것은 아닙니다.
4. [미확인] 특정 원사이트/출력의 보호 표현·실질적 유사성·혼동·성과성과 누적 DB 이용 경계. 한국 웹사이트 직접 대응 확정판결·법정 유사도 안전선은 확보하지 못했습니다. 본문 판결은 일반 법리 및 인접 사진/서체 사례입니다.[7][11][18]
5. [미확인] 선정할 스톡·생성 이미지·웹폰트의 실제 라이선스, 관련 색채상표·글자체/화상 디자인 등록 범위, 디자인보호법 기준일 현행본과 확보 연혁본의 전 조문 대조. 이름이나 ‘유사 폰트’만으로 확인이 끝나지 않습니다.[13][14][15][19][20]
6. [미확인] 미국 웹사이트 특화 trade dress·AI 입력 직접 판례와 최신 학습 소송 결과, EU 회원국 이행법·opt-out 구현·본 추론의 TDM 해당성 및 전체 준거법. 미국 판결은 부분 발췌만 확보했고 EU 제3/4조 일부 문단도 추출 누락이 있습니다.[10][16]
7. [미확인] 최종 선정 API 계약의 적용 버전·주문서·배상 제외·보관 정책과 고객 납품 형태에 대한 적합성. 공식 일반 계약 두 사례를 확인한 것이 전 공급자나 개별 고객 계약의 포괄 검증은 아닙니다.[6][9]

제외 준수: 실제 원사이트 디자인 추출·실험, 계정 생성, 외부 발송, 대량 수집, GDWEB·dbcut 조회·추출을 하지 않았습니다. 공개 법령·판례·공식 약관·정부 공지만 조회했습니다. 검색된 비공식 해설은 검색어 보완에만 사용하고 근거로 인용하지 않았습니다.

도구 한계: execute_code는 무인 실행 정책으로 차단되어 실행되지 않았고, 정적 HTTP 조회를 terminal의 Python 표준 라이브러리로 대체했습니다. bs4·fitz가 없어 HTML은 표준 파서, PDF는 web_extract의 원문 반환을 사용했습니다. OpenAI 정적 HTTP 403은 web_extract의 재조회로 입력/출력 조항 원문을 확보했습니다. 마지막 디자인보호법 추가 조회는 web_extract 결제 잔액 오류(402)로 차단되었으며 대체 HTTP도 법령 셸만 반환해 최신본 대조는 미확인으로 남겼습니다. 유료 결제·계정 변경·다른 브라우저 사용은 하지 않았습니다.
