## 1. 영환님 결정 (2026-09-26, "전부 A") — SPEC 10절을 "결정"으로 바꾸고 본문에 반영

  - 지난 확정(`confirmed` 버전의 `base`) 이후 **보드에서 바뀐 필드**는 보드 값이 이기고, **그 필드와 겹치는 조정은 지운다**(예: 보드 모션 변경 → `adjustments.motion` 삭제). 대비 보정은 대상 역할의 base 값이 바뀌면 지운다(기존 `{role, from, to}` 규칙 유지).
  - **바뀌지 않은 필드의 조정은 이어받는다.**
  - 확정 **전** 보드 초안 패널에 "이어지는 조정 N개 · 지워지는 조정 M개"를 보이게 한다(목록은 펼침 또는 설명으로, 색 하나로만 알리지 않기). 저장 결과 = 화면에 보인 결과(보드 AC-24 "보이는 초안 = 저장값"을 이 규칙으로 다시 성립시킨다).
  - 겹침 판정 표(보드 필드 ↔ 조정 필드: 모션·밀도·대비·목적·보정)를 6.1에 표로 둔다. 겹치지 않는 조합(예: 밀도는 보드에 없음)은 "항상 이어받음"으로 명시.
