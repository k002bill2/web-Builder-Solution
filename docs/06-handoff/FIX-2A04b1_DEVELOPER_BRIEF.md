## 1. 결함 (Codex, L1)
`app/scripts/check-bundle-size.mjs` 41~46행: `useCompareBoard.ts:133`의 `import("./carryOverPanel")`은 확정한 프로필의 최신에 조정이 있으면 **사용자 조작 없이 진입 직후 자동 실행**되는데, `ROUTE_CONDITIONAL_DYNAMIC`(예산 판정 밖)으로만 분류돼 125KB 합계에 더해지지 않는다. 그 경로의 `/compare` 진입 직후 ≈ 124.46 + 2.52 = **126.98KB(초과)**.

## 2. 분류 규칙 (스크립트에 주석으로 명시)
- **자동**(진입 직후 합계에 포함): 사용자 조작 없이 렌더·effect·로더에서 실행되는 dynamic import. 조건부여도 **그 조건이 참인 시나리오**의 합계를 따로 계산해 125KB로 판정한다(예: `/compare`(조정 있음) = 기본 진입 직후 + 자동 조건부 closure 중 아직 없는 파일).
- **조작 뒤**(예산 밖, 크기만 출력): 클릭·펼치기·저장 등 사용자 조작 핸들러 안에서만 실행되는 import. 재확정 이어받기 규칙(`memoryCompareBoardRepository.ts:54`, 확정 클릭 뒤)·조정 저장 본문(`memoryProfileRepository.ts:38`, 호출 시)이 여기에 해당하는지 **호출 지점을 코드로 확인**해 분류하고 근거를 REPORT에 적는다. 확인 못 하면 자동으로 분류.
- 판정 대상 라우트·시나리오 목록은 스크립트 상수 하나로 관리, 목록 키가 manifest에 없으면 실패(기존 가드 유지).

## 3. 고칠 것 (순서)
1. **스크립트 먼저 (TDD)**: 위 규칙으로 바꾸고, 지금 코드에서 `/compare`(조정 있음) 시나리오가 **실패(>125)하는 것을 RED로 기록**(로그). 스크립트 판정 함수에 단위 테스트가 가능하면 추가(`scripts` 테스트 위치는 기존 관례, 없으면 REPORT에 수동 RED 로그로 대체).
2. **패널 분할**: 자동으로 받는 것은 **캡션 계산에 필요한 최소**("이어지는 N개 · 지워지는 M개" = `carryOverAdjustments` 결과 개수)만. 목록 문구·대비 상세(`adjustmentText`·`profileContrast`의 목록용 부분 등)는 `details` "조정 목록"을 **펼칠 때** import(조작 뒤). 펼침 중 로딩 상태 문구·실패 시 문구, 포커스·`aria-expanded` 유지, 펼치기 전 캡션 개수 = 펼친 뒤 목록 개수(P-AC-39 ① "패널 = 저장값" 유지).
   - 이어받기 판정 자체에 대비 계산(C-3·C-4·C-5)이 필요하면 캡션 청크에 남는다 — 그 크기를 실측해 보고.
3. 그래도 `/compare`(조정 있음) 진입 직후 여유 < 0.3KB면 순서대로: (a) 대비 계산 중 판정에 필요 없는 부분 분리 (b) P-B7 `Callout` 공유 청크 정리 (c) BUNDLE-01 C8. 모두 해도 안 되면 **예산 변경 없이 멈추고 근거를 REPORT에 커밋**.
4. **Q1 멱등 키 (TDD)**: `saveAdjustments`에 a1 보드 확정과 같은 r3 계약 — 멱등 키 = (profileId, expectedLatest, 정규화한 조정)의 **별도 기록**(보드 `commits` 슬롯 재사용 금지, A-Q4 유지). 판정 순서: 멱등 키 일치 → 이전 결과 반환(새 버전 0) → 이후 기존 순서(모양 → NOT_FOUND → STALE_PROFILE → RANGE_VIOLATION → 보정 from → 변경 없음). 커밋 뒤 응답 실패(`phase` 응답 단계 실패 주입) → 같은 인자 재시도 = 같은 결과, 다른 조정 = 기존대로 STALE. 트랜잭션 롤백 시 멱등 기록도 롤백.

## 4. 수용 기준
- B-1 스크립트: `/compare`(조정 있음) 시나리오 합계가 출력되고 125KB로 판정된다. 수정 전 코드에서 실패(RED 로그), 수정 후 통과.
- B-2 모든 라우트·시나리오 첫 화면 ≤ 100 · 진입 직후 ≤ 125, 여유 ≥ 0.3(첫 화면 `/compare`는 현재 0.51 — 줄지 않게). 전/후 표.
- B-3 P-AC-38·39 화면 테스트 유지 + 펼치기 전후 개수 동일, 펼칠 때 로딩·실패 문구 테스트.
